# Teral website

The official website for [Teral](https://github.com/zuhaibullahbaig/teral), a native Linux file manager written in Rust with GTK4.

## Development

```bash
bun install
bun run dev
bun run build
```

Release information is maintained in `src/data/project.ts`.
